# .github — org defaults for anam-145

Default community-health files inherited by **every repo in the org that doesn't have its own**:
- `.github/PULL_REQUEST_TEMPLATE.md` — default PR description
- `.github/ISSUE_TEMPLATE/` — default bug / feature issue templates + chooser config

A repo overrides any of these by committing its own file of the same name (e.g. a cell-specific
template). See [`anam145-infra/docs/PR_WORKFLOW.md`](https://github.com/anam-145/anam145-infra/blob/main/docs/PR_WORKFLOW.md).
